# Creador de Soluciones con IA

Hackatón DonWeb. Plataforma donde un negocio local dice **qué rubro es** y la IA le arma su solución.

## Problema
Un negocio local pierde ventas porque atiende consultas y pedidos a mano, por WhatsApp o teléfono: mensajes que se pierden, pedidos mal anotados, clientes que esperan y se van.

## Idea
Una landing con un asistente: *"Decime qué rubro sos y te ayudo con tu problemática."*
A partir de la conversación, el sistema configura para el negocio:

1. **Web con asistente** (chat/avatar que responde consultas).
2. **Catálogo + bot de pedidos** (restaurante, ferretería, etc.).
3. **Turnos con IA** (peluquería, consultorio, etc.).

Un panel de administración multi-negocio (multi-tenant) permite gestionar todo.
