🧠 Inteligencia artificial del vendedor DeepSeek

Tu tienda ya trae DeepSeek integrado (IA de Marcia). Si querés, conectá tu propia cuenta de DeepSeek y el vendedor virtual usa tu IA. La clave se guarda en el servidor, separada de tus datos públicos, y nunca se vuelve a mostrar.

📘 Cómo conseguir tu API key de DeepSeek (3 minutos)
  1. Entrá a platform.deepseek.com y creá tu cuenta.
  2. En Top up cargá algunos dólares (alcanza para miles de conversaciones).
  3. En API keys → Create new API key copiá la clave que empieza con sk- (se muestra una sola vez).
  4. Acá abajo elegí "Mi cuenta de DeepSeek", pegala y tocá Guardar y probar.
